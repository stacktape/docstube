Open source is great for distribution.

Why open-source spreads on its own

Free channels reward it

GitHub trending and stars, Hacker News, Reddit, dev newsletters feature open-source for free. Paid SaaS has to buy its way in.

Instant time to value

Free, MIT, runs locally. A developer goes from seeing it to running it on their repo in minutes.

No barriers to entry

No procurement, no security review, no budget sign-off. A developer just installs it.

Developers trust and share it

People recommend open tools freely. Some become contributors: free work, free word of mouth.

So we don't need a big marketing team or budget to get started.

First growth play

The drift report

The first thing we'll run: point docstube at well-known open-source projects and publish what it finds. "Your docs disagree with your code in N places." It is useful, it is easy to share, and it shows the product working on code people already know. Then we offer to fix and host those docs for free.
