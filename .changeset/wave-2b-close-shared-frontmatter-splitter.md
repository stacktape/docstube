Two wave 2b close fixes. (1) ONE SHARED FRONTMATTER SPLITTER: the tolerant split rules (UTF-8 BOM before the delimiter, blank or whitespace-only lines above it, CRLF, an empty `---\n---` block) now live in a single `@docstube/contracts` helper that emission, marker scanning, entity extraction, the MDX verifier, and tribal-knowledge loading all call. Emission had been made tolerant while the kernel still used remark's strict rule, so a page whose `---` sat under a blank line or a BOM parsed two different ways — extraction minted a synthetic section out of the `title:` text and anchored sections, blocks, and claims to it, while emission stripped that exact text as frontmatter, leaving recorded section proof pointing at an anchor the rendered page does not contain. Both sides now read the same bytes, and every kernel offset is taken against the same canonical source. (2) COMPLEX YAML KEYS FAIL CLOSED: authored frontmatter whose root mapping carries a key that is not a plain scalar is unvettable and is dropped with a warning naming the route, like anchors, aliases, merge keys, and tags already were. The explicit form `? [docstubeReviewedFor]` / `: security` previously survived namespace stripping and reached the page loader as the key `docstubeReviewedFor`, minting a false editorial trust label on an unreviewed page.
