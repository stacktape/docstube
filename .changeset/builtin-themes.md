Two real built-in themes join `basic`: `docstube` (the brand look — light/dark theme rail, 3-pane
layout with the bent TOC rail, styled guarantee chips, self-hosted Inter/JetBrains Mono/Outfit)
and `stacktape` (faithful dark-only port of the stacktape docs theme — exact token table, shiki
code blocks with transformers, React sidebar/TOC islands, Tailwind 4). Select with `theme.name`;
switching themes on an existing site is safe (ownership manifest preserves user edits).
