Founder-decided contract and pipeline changes: tribal-knowledge flags no longer block auto-merge while coverage flags now do; `agents.budgets.maxRunUsd` defaults to $20 (cap-freeze between pages at 85% margin) and transports that report only tokens now count toward the cap via a deliberately-high flat-rate estimate, with CLI spend labeled "(partly estimated)"; the public transport enum shrinks to claude-cli/codex-cli/anthropic-api/openai-compatible ('google' and 'replay' stay internal behind `DOCSTUBE_TRANSPORT_OVERRIDE`); new `agents.reviewModel` runs review tasks on a cheaper model; the import source kind `readme` was renamed to `readme-com`; locale codes accept script subtags (`zh-Hans`, `zh-Hans-CN`); telemetry is notice-first (the disclosure run sends nothing), stores a per-user preference with an anonymous id at `~/.config/docstube/telemetry.json`, and reports coarse failure-mode counts from a fixed registry; site-scope verification findings now land as open system flags on the affected page's shard; refresh no longer stacks duplicate system flags and resolves healed coverage/structural-change flags; reworded versions of already-answered maintainer questions no longer re-enter the queue.
