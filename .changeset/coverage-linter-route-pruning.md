The coverage linter ships, and emission becomes a true reconciler. (1) COVERAGE LINTER (PRODUCT §1.2 "no hidden denominator"): a deterministic pass now reads the visible prose OUTSIDE every `<Claim>` marker and reports assertion-shaped sentences — ones naming a code identifier AND carrying an assertion signal (a numeric literal, or one of `defaults to` / `is set to` / `equals` / `returns` / `throws` / `requires` / `must` / `always` / `never` / `is exported` / `is defined` / `is available`) — as UNMARKED ASSERTIONS on the page's claim ledger. This is user-visible on the badge: the chip now reads e.g. "3 of 3 claims checked · 2 unmarked assertions", and the complete/green state requires zero unmarked assertions, so a writer who simply omits markers around factual prose can no longer manufacture a complete page. The report is non-blocking — it never fails a page or triggers a repair — and the detector is deliberately high-precision/low-recall for 0.1.0. (2) OBSOLETE ROUTES ARE PRUNED: emission now deletes generated routes and their `.md` twins that no page in the current manifest routes to, so a removed page or a changed slug stops serving stale prose and proof; pruned paths are reported in the CLI output. (3) A punctuation-only heading no longer steals a real heading's Astro anchor, and its unresolvable section chip is omitted. (4) A translator transport failure is now a non-blocking localization failure: the source page ships, the locale route falls back to source content, and the run no longer crashes.
