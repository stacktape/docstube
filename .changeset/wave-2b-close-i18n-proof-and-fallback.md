Wave 2b close, i18n proof correctness round. MARKER ISOMORPHISM: translation hygiene now compares the translated artifact's Claim marker id inventory against the source page's markers with exact set equality — any rename, addition, or removal fails that translation on the existing nonblocking path (the source page is unaffected). RENDITIONS INHERIT CANONICAL PROOF: a locale route's reader-facing correctness proof (claim counts, contradicted/unchecked marks) now derives from the canonical source shard's ledger and evidence — language-independent per the strict-isomorphism decision — so a translated rendition of a 1/1-checked page renders 1/1 checked instead of the previous 0/0-unverified, while the MDX↔shard binding check still runs against the locale bytes. STALE LOCALE MDX NEVER SERVED: when a locale shard is hashless (failed translation or retranslation), emission ignores whatever locale MDX remains on disk and serves the fresh source content under the locale route with a visible not-yet-translated notice (`docstubeSourceFallback` frontmatter + the new `dt-source-fallback` chip in every built-in theme), reporting the ignored stale file. EMISSION AFTER PARTIAL FAILURE: both `docstube generate` and the wizard's background run now re-emit the site even when the pipeline throws after pages were persisted (translation/transport errors), so rendered routes never drift from the new shards; the run error is surfaced after emission. Tag-regex precision: the script/style prohibition no longer matches custom elements like `<style-guide>` — the tag name must end at whitespace, `/`, or `>`.
