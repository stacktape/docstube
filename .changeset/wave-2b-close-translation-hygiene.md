Three fixes from the wave 2b regression gate. (1) Failed translations persist hashless: when a translation fails and no locale MDX is written, the translation shard persists WITHOUT `mdxContentHash` — the binding hash is minted only on the success path from the exact locale bytes the pipeline persists, so any later emission of a fallback or stale file renders loud-UNVERIFIED instead of binding to bytes that were never written. (2) Expression and translation hygiene: the page-script scan now also inspects MDX expression nodes — `{<script>…</script>}` / `{<style>…</style>}` (flow and inline, case-insensitive tag match, never a word match) are rejected as `page-script`; and translated MDX passes the same page hygiene scan (script/style including expressions; malformed/duplicate/attribute-bearing Claim markers) before persistence, failing the translation nonblocking when hygiene fails. (3) Wizard emission consistency: the wizard's background generate/refine run now ends with the same site emission step the CLI generate command runs, so rendered routes and their claim counts never drift from the updated shards; emission warnings surface in the wizard's output the same way.
