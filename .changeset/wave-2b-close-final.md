Wave 2b close, final hardening round. SUBJECT BINDING is now bidirectional and root-mandatory: a claim's evidence mints only when the codemap display name of the referenced symbol — the subject's ROOT identifier — occurs as a case-sensitive identifier token in BOTH the visible marker prose AND the predicate (the same both-sides shape as cited-value binding). Predicate-only occurrence is rejected as laundering (readers never see the predicate), and cited-value path segments are context only — a common leaf like `config` can no longer bind an unrelated `configFileNames.config` value. Anchoring rejects violations with the repair-eligible `subject-unbound` error; verification re-checks the same rule and mints nothing. Generated sites now apply the inline contradicted/unchecked claim marks PARSE-SAFELY: the kernel primitive defers its DOM queries to `DOMContentLoaded`, so marks attach even though every theme mounts it before the content slot (verified against a built fixture site). The dirty-tree honesty probes (run start AND end, in generate/maintain/refine) now ignore docstube's OWN declared outputs — the committed `.docstube/` state and the generated site under `outDir` — so a normal successful run never self-marks dirty while real source dirt is still detected.
