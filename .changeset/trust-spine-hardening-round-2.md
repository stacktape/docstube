Trust-spine hardening (wave 2b-iii round 2). Cited-value binding is now bidirectional and lexical: the asserted scalar must appear in BOTH the visible marker prose (rendered text — link URLs and attributes excluded) AND the claim predicate, with real number tokenization (".5" is 0.5, digits inside identifiers never bind), and multiple conflicting or negated values reject with a repair error. Behavior claims check only from assertion-bearing snippet executions: the kernel re-verifies that the executed source contains a failure-capable assertion construct and binds the evidence to the exact page block by content hash, recording snippet identity and the actual runtime (bash records bash). Page generation keeps every attempt's artifact, ledger, provenance, matching, and reviews as one atomic candidate, so a failed final attempt can never ship an earlier attempt's trust state. The reader surface now renders literal claim counts ("N of M claims checked"), a loud contradiction banner with per-claim contradicted marks, and the "reviewed for" label only from a genuinely completed review — the proven/scored guarantee-label ladder is gone. Manifest shards enforce exact ledger↔evidence set equality, ledger↔page linkage, and revision consistency; claim-identity threading uses deterministic maximum bipartite matching; dirty working trees are labeled honestly in provenance; persona reviews are strictly editorial; and the unused reserved `autonomy`/`screenshots` config stubs were removed (they now fail validation if present in docstube.yml).
