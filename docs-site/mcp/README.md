# Docs MCP server

This directory contains a self-contained MCP (Model Context Protocol) server for this
documentation site, generated by docstube. It needs Node only — no npm install.

```bash
node mcp/docs-mcp-server.mjs --port 3333
```

The server speaks the MCP Streamable HTTP transport in stateless mode: a single POST endpoint
(`http://127.0.0.1:3333/`) accepting JSON-RPC 2.0 `initialize`, `tools/list`, and `tools/call`
messages. Notifications are acknowledged with HTTP 202. There is no SSE stream and no session
state — every request is independent, which is all a static docs site needs.

Tools (DeepWiki de-facto names):

- `read_wiki_structure` — the page tree (titles, slugs, URLs) from `mcp/site-index.json`.
- `read_wiki_contents` — one page as raw markdown, served from the `public/<slug>.md` mirrors.
- `ask_question` — returns the most relevant page by keyword scoring over titles and content.
  This is honest local search, never a fabricated LLM answer; hosted Ask-AI is a docstube
  Cloud feature.
